# plan-written stub

Record the moment in the file `moment.log` at the root of the current project, using
your file tools (not the shell), with the plan's path you were passed in place of
`<plan path>`:

- If `moment.log` doesn't exist, create it containing the single line
  `plan-written <plan path>`.
- If it exists, add that line at its end, keeping what is already there.

Then continue with what you were doing. Do nothing else.
